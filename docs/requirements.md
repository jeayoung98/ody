# ODY 요구사항 명세서

> 출처: Notion 「요구사항 명세서」 스냅샷 (최종 편집 2026-09-03). 정본은 Notion.
> 기능 명세서(Back) 페이지는 인라인 DB에 샘플만 있어, 실질 기능 요구사항은 이 문서 §4 표를 기준으로 한다.

약 920만 곡을 소리의 성질에 따라 하나의 지도 위에 배치하고, 사용자가 자신의 위치에서 원하는 지점까지 탐색하면서 같은 공간에 있는 다른 사용자와 음악을 공유할 수 있는 음악 탐색 서비스.

## 1. 문서 개요

### 1.1 목적
ODY MVP 개발에 필요한 기능·비기능 요구사항을 정의한다. 기획서의 서비스 방향을 개발 가능한 단위로 분해하여 FE·BE·데이터 담당자가 동일 기준으로 진행하도록 한다. 본 문서는 화면 설계서·API 명세서의 상위 문서이며, 두 문서는 본 문서의 기능 ID를 참조한다.

### 1.2 범위
- 포함: MVP 기능 요구사항, 우선순위·확정 여부, 구현에 영향 주는 운영 정책, 성능/보안/데이터/호환성 비기능 요구사항
- 제외: 화면 레이아웃·UI 상세, API 엔드포인트/스키마, DB 물리 설계, 인프라·배포 절차

### 1.3 용어 정의

| 용어 | 설명 |
|---|---|
| 좌표 | 곡의 음향 측정값에 차원 축소를 적용한 값. 곡마다 고정, 이후 불변 |
| 주성분 | 전체 곡 대상 1회 계산 후 고정한 차원 축소 결과. 설명력 순 정렬 |
| PC 레이어 | 소분류 장르 아래 단계. 고정 주성분을 설명력 순으로 하나씩 적용해 나눈 계층 |
| 노드 | 지도의 한 영역. 장르 단계 또는 PC 레이어 단계에서 곡들이 묶인 단위 |
| 축 라벨 | 지도 두 축을 일상 표현으로 바꾼 문구 |
| 여정 | 출발·도착 지점 사이를 잇는 곡의 순서 목록 |
| 주변 친구 | 음악 지도상 가까운 좌표의 다른 사용자 (물리적 거리 무관) |
| 반응하기 | 같은 영역 사용자에게 정해진 이모지 전송 |
| 따라가기 | 다른 사용자의 화면 이동을 실시간 동반 |
| 미리듣기 | 외부 음원 링크를 통한 짧은 재생 |
| 사용자 좌표 | 온보딩 입력 기반 사용자의 지도상 위치 |

## 2. 서비스 개요

### 2.1 배경 및 문제
기존 추천은 결과 목록만 제시할 뿐 근거와 사용자의 현재 위치를 보여주지 않는다. 장르 이름만으로 두 음악의 차이를 판단할 수 없고, 타인의 취향 확인도 완성된 플레이리스트 열람 수준이다. 본 서비스는 공개 데이터를 가공해 곡마다 고정 좌표를 부여하고, 지도 위에서 위치 확인·방향 탐색·동반 탐색을 가능하게 한다.

### 2.2 페르소나
- **김도현 (24, 대학생)**: 추천이 다 비슷하게 느껴짐. 다른 영역과 그 중간 과정을 들어보고 싶음. → 온보딩·계층 탐색·여정·미리듣기
- **이서연 (27, 직장인)**: 특정 장르를 깊게 팜. 세부 장르 차이를 소리로 확인하고 싶음. → 계층 탐색·PC 레이어 확대·주변 탐색·상세
- **박지훈 (22, 대학생)**: 취향 맞는 사람과 접점을 원함. → 주변 친구·반응하기·따라가기
- **한서우 (17, 고등학생)**: 취향이 아직 미형성. 흩어진 취향을 관통하는 축을 눈으로 확인하고 싶음. → 여정(곡→곡)·경로 시각화·축 라벨·상세·주변 탐색

## 3. MVP 범위 정의

### 3.1 포함
- **계정과 진입**: 회원가입, 로그인, 온보딩 선호 입력, 초기 좌표 생성, 마이페이지
- **지도 탐색**: 지도 화면, 대·소분류 장르 계층, PC 레이어 단계, 축 라벨, 주변 탐색, 곡 검색, 음악 상세, 미리듣기
- **여정**: 출발·도착 지정, 경로 생성·시각화, 플레이리스트 생성·곡 추가
- **사용자 연결**: 주변 친구 목록, 접속 여부, 반응하기, 따라가기, 계정 공개/비공개

검증 목표: ① 고정 좌표 계층 탐색이 세부 단계까지 의미 있게 동작하는가 ② 두 지점 경로가 자연스러운 흐름으로 생성되는가 ③ 반응하기·따라가기만으로 사용자 연결이 성립하는가.

### 3.2 제외 (향후 확장)
프로필·피드, 팔로우/팔로잉, 좋아요·스크랩(소셜 묶음), 랭킹(집계 기준 미확정), 음원 저장·스트리밍(저작권), 신곡 실시간 유입, 취향 변화 연대기, 청취 밀도 히트맵, 알림.
