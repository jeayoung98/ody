# ODY 기능 명세

> **이 문서가 기능의 기준(Source of Truth)이다.**
> **프론트 전용 문서가 아니다.** 프론트·백엔드·AI 모두 이 문서의 기능 ID(`SEARCH-01`, `PATH-01`, `SOCIAL-07` …)로 이야기한다.
> 코드 작성 요청이 이 명세와 다르거나 명세에 없는 기능이면, 구현 전에 요청한 개발자에게 더블체크하고 "명세와 다르므로 팀 전체와 상의가 필요하다"고 알린다.
> 명세 수정은 기획 담당자 확인을 하나씩 받은 뒤에만 반영한다. 미확정 제안은 하단 "변경 제안" 섹션에 둔다.

- 버전: **v1.5** (AUTH-01/02 가입·로그인 = 구글 소셜 + 이메일·비밀번호 두 가지로 확정, 가입 직후 닉네임 설정(중복 불가) 추가, 변경 제안 #1 반영. 나머지 변경 제안은 아직 미반영)
- 최종 수정: 2026-09-12

## 파트 간 동기화 규칙

**한쪽만 바꾸고 끝내지 않는다.** 아래 상황이 생기면 문서를 고치고 **반대편 파트에 알린다.**
자세한 절차는 [루트 CLAUDE.md §3](../../CLAUDE.md) 참고.

| 어디서 시작됐나 | 해야 할 일 |
| --- | --- |
| 백엔드가 API·응답·에러 코드를 바꿨다 | 해당 기능 항목과 아래 "구현 현황"을 갱신하고, **프론트에 화면을 맞추라고 알린다** |
| 프론트에 없는 필드·API·소켓 이벤트가 필요해졌다 | [BACKEND-NOTES.md](BACKEND-NOTES.md)에 항목을 추가하고, **백엔드에 맞춰달라고 알린다.** 없는 필드를 있는 척 구현하지 않는다 |
| AI 쪽 좌표 차원·유사도·대표곡 선별 기준이 바뀌었다 | 지도·추천 항목을 갱신하고 **프론트·백엔드 양쪽에 알린다** |
