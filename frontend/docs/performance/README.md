| 문서 | 역할 |
| --- | --- |
| 여기 (`docs/performance/`) | **개선 사례.** 왜 느렸고, 무엇을 바꿨고, 얼마나 좋아졌나 |
| [`../../PERF-LOG.md`](../../PERF-LOG.md) | **원시 측정값.** 커밋별 FPS·그리기 시간·번들 크기 행 |

## 쓰는 법

### 규칙

1. **개선 전·후를 같은 방법으로 잰다.** 방법이 다르면 비교가 아니다. 잰 방법을 문서에 적는다.
2. **추정값을 수치 칸에 적지 않는다.** 못 쟀으면 `미측정`이라고 쓴다. 근사치면 근사치라고 밝히고 무엇의 하한/상한인지 적는다.
3. **개선이 없었으면 없었다고 쓴다.** 바꿨는데 그대로거나 나빠졌으면 그 사실이 더 쓸모 있다.
4. 원시 수치를 `PERF-LOG.md` 에 넣었으면 그 행을 링크한다.
5. 파일 이름은 `NNN-영문-슬러그.md`. 번호는 순서대로.
