# 017. 폰 주변 탐색 라벨이 화면 밖으로 잘리고, 가두면 서로 겹침

- 이슈: S15P21A405-715
- 커밋: `0e57fca1` · `d9bdfcb2` · `a0cd6770` · `e217565e` · `cfc4d1b5`
- 날짜: 2026-09-27

## 증상

1. 폰(360×780)에서 별을 눌러 곡을 고르고, 윗줄 주변 탐색을 누른다. 시트는 1단이다.
2. → 끝에 있는 이웃의 라벨이 화면 밖이나 시트 밑으로 나가 잘린다.

사용자 보고: "눌렀을 때 UI 나 화면 크기 때문에 잘리는 부분이 있다". 별자리 뷰도 끝 별의 라벨이 반쯤 화면 밖이었다.

## 처음 의심한 것 (둘 다 틀렸다)

**1. "라벨을 미는 계산이 화면을 모른다"** — `separateLabels` 는 겹친 쌍을 떼어 놓기만 하고 화면 경계를 몰라서 밖으로도 민다.
남은 화면을 경계로 주고 밀 때마다 안으로 되돌리게 했다(`0e57fca1`). 화면 밖은 0 이 됐지만 **글자끼리 포개졌다.**

**2. "라벨이 넓어서"** — 글줄 폭 상한을 남은 화면 폭의 42% → 36% 로 줄이고, "주변 보기 ›" 자리를 선택한 이웃에만
비워 두게 했다(`d9bdfcb2`). 여전히 포개졌다.

둘 다 라벨 크기를 조금 깎는 쪽이었다. 문제는 크기가 아니라 **넓이**였다.

## 증거

측정은 개발 서버의 브라우저 패널에서 했다. 한 프레임 동안 `fillText` 를 가로채 글자마다 화면 사각형(`measureText` 의
실제 잉크 경계)을 적고, 다른 라벨의 글자와 겹치는 쌍을 셌다.

`d9bdfcb2` 상태, 360×780, 시트 1단, 가운데 곡 I Luv It:

```
남은 화면: x 0–360, y 153–527 (374px) — 위 HUD 153px, 아래 1단 시트·플레이어·내비바 253px
화면 밖 줄 0, 글자가 포개진 쌍 3
  インドア系ならトラ… / #9 · DNB 4 PEA
  New Me / KYON-C
  #6 · Ella Eyre / #7 · MINMI fea
```

같은 고리를 엔진 배치 그대로 노드에서 다시 돌렸다(계산, 실측 아님).

```
라벨 상자 넓이 합(간격 8px 포함) / 경계 넓이 = 0.94
엔진 상자끼리 겹친 쌍 12   (글자로는 3쌍 — 엔진 상자가 별 자리까지 품고 글자 폭도 넉넉히 어림한다)
```

지도 곡 172개로 고리 201개를 만들어 같은 계산을 폰 크기마다 돌렸다. 미는 방식으로는 **360×760 에서 겹침 없는 고리가 0%** 였다.
라벨을 줄이거나(0.9배·상한 30%) 한 줄로 만들고 안내 줄까지 빼도 27% 를 넘지 못했다.

## 원인

**좁은 화면에는 두 줄 라벨 열한 묶음이 들어갈 자리가 없다.**

고리 반지름은 남은 화면 짧은 변의 36% 라 360×780 에서 바깥 130px, **안쪽 75px** 이다(`MapEngine.ringR`, `PROBE.innerRing`).
안쪽 고리 둘레 471px 에 라벨 다섯(한 묶음 80~142px)과 가운데 곡의 제목·안내 줄(200px)이 함께 서야 한다.

그리고 `separateLabels`(`engine/probe-layout.ts`)는 겹친 쌍을 덜 겹친 축으로 반씩 미는 방식이다. 넓은 화면에서는
고리가 화면보다 한참 작아 이걸로 충분했다(S15P21A405-697). 경계에 막히면 밀고 되돌리기를 되풀이하다 겹친 채 끝난다.

## 조치

**폰에서만 바꿨다**(엔진 `isNarrow()` — 768px 미만). 넓은 화면의 `laidOutRing` 은 dev 코드를 글자 그대로 되돌렸다.

- 라벨을 한 줄로 — 이웃은 제목만, 가운데는 `NEARBY · 유사도 상위 10곡 · …` 줄 없이(`draw-map.ts` `drawProbe`).
  가수는 누르면 시트에 뜨고, 안내 줄은 위 뷰 칩·레이어 이름과 같은 말이다.
- **앞 순위부터 원래 고리 자리에서 가장 가까운 빈자리에 놓는다**(`placeLabels`, 한도는 반지름 × 0.9).
- 그래도 부딪히는 낮은 순위는 **글자만 숨긴다**(`cullLabels`). 선택한 곡과 가운데 곡은 늘 보인다.
- 글자가 숨은 곡의 별도 빈 곳에 둔다(`PROBE_LABEL.narrowStarPx`) — 처음엔 제자리에 두었더니 10위 별이 9위 제목 상자
  안에 그려져 안 보였다(실측, `e217565e`).
- 선택한 이웃의 "주변 보기 ›" 는 제목 밑이 먼저고, 시트 밑이거나 다른 별을 덮으면 별 위로 올린다 — 390×844 에서 선택한
  10위의 링크가 9위 별을 덮었다(실측, `cfc4d1b5`).
- 선택해도 별 자리는 다시 놓지 않는다 — 누를 때마다 옮기면 누른 별이 달아난다.
- 글줄 상한 36% → 30%(360px 에서 108px).

두 줄을 살리고 같은 방식으로 놓으면 360×760 에서 보이는 라벨이 71% 로 떨어져(계산) 한 줄을 골랐다.

## 남은 것

- 이웃을 누르면 곡 시트가 2단으로 올라간다(S15P21A405-703 규칙). 남은 화면이 374 → 222px 로 줄어 고리가 다시 놓이고,
  라벨 4개가 숨는다(실측, 360×780). 주변 탐색에서도 2단으로 열지는 사용자 결정 대기.
