# 018. 1단으로 열린 여정 시트를 2단으로 올리면 재생 줄이 플레이어 바에 깔림

- 이슈: S15P21A405-714 (S15P21A405-712 와 맞물려 드러남)
- 커밋: `e41e5c27` · `400da72e` (걷어냄) · `add5479e`
- 날짜: 2026-09-27

## 증상

1. 폰(360×780)에서 출발·도착을 정해 경로를 만든다. 여정 시트가 1단으로 열린다(S15P21A405-712).
2. 시트 손잡이를 눌러 2단으로 올린다.
3. → 출발·도착 밑의 "총 재생 · 경로 지우기 · 순차 재생" 줄이 아래 플레이어 바에 반쯤 가려진다. 2단은 이 줄 아래에서
   멈춰야 한다(S15P21A405-714).

## 처음 고친 방식 — 값은 맞았지만 화면이 떨렸다

"머리글이 펴지는 걸 모른다" 가 원인이라 보고, 머리글을 `ResizeObserver` 로 같이 지켜보며 다시 재게 했다.

- `e41e5c27`: 내용 상자로 봐서 175 → 196px 로만 늘었다. 위아래 여백이 펴지는 동안은 알림이 안 왔다.
- `400da72e`: 테두리 상자로 보자 필요한 값(208px)에서 멈췄다.

그런데 머리글이 펴지는 **동안 매 프레임** 값이 바뀌었고, 그 값이 지도 가림폭으로도 가서 지도가 따라 떨렸다 — 사용자 보고
"UI 올릴 때마다 화면이 달달 떨린다". 그래서 두 커밋의 방식을 걷어냈다(`add5479e`).

## 증거

2단에서 시트 요소(`[data-sheet]`)의 `--sheet-stop` 과, 그 자리에서 같은 식으로 다시 잰 값:

```
고치기 전      --sheet-stop 175px   다시 재면 208px   (33px 모자람 — 재는 중에 머리글이 접혀 있었다)
머리글 관찰    --sheet-stop 196px   다시 재면 208px   (12px 모자람 = 머리글 위아래 여백)
테두리 상자    --sheet-stop 208px   다시 재면 208px
```

"경로 지우기" 버튼은 고치기 전 y 599–632 였다(DOM). 플레이어 바 위끝은 스크린샷에서 어림하면 615 근처라 버튼 아래 절반이
깔렸다. 2단에서 재생 줄 묶음 윗끝은 시트 윗끝에서 70px 이었다(DOM) — 아래 `SHEET_HEAD_PX` 의 근거다.

## 원인

`hooks/use-sheet-stop.ts` 는 **멈출 요소의 아래끝 − 시트 위끝**을 재고, 요소 **크기**가 바뀔 때만 다시 잰다.

`app/globals.css` 는 1단에서 머리글 높이·여백을 접는다(S15P21A405-703, "1단은 머리글 없이"). 그래서:

- 1단으로 **처음 열린** 시트는 머리글이 접힌 채로 잰다 → 요소가 머리글만큼 위에 있어 값이 짧다.
- 2단으로 올리면 머리글이 펴져 요소가 내려가지만 요소 크기는 그대로라 다시 재지 않는다.

프로필(`feed-header`)은 같은 훅을 쓰지만 2단으로 열려 머리글이 펴진 채로 재기 때문에 드러나지 않았다. 여정이 712 에서
1단으로 열리게 바뀌면서 처음 드러났다.

1단 높이를 재는 `use-sheet-peek` 에는 이 문제가 없었다 — **본문 윗끝에서** 재기 때문이다. 본문 안의 거리는 머리글이 접히든
펴지든 그대로다.

## 조치 (`add5479e`)

`use-sheet-stop` 도 `use-sheet-peek` 처럼 **본문 윗끝에서** 잰다. 2단 높이 = 본문 안 거리 + 2단의 머리글 몫(`SHEET_HEAD_PX`
70px, 위 DOM 값) + 아래 여백 14. 머리글을 지켜보지 않으므로 시트가 움직이는 동안 값이 바뀌지 않는다.

같은 커밋에서 사용자 요청대로 **1단도 재생 줄까지** 걸리게 했다 — 1·2 단을 재는 자리가 출발·도착 상자에서 재생 줄까지 감싼
묶음(`journey-top`)으로 옮겨 갔다. 1단은 머리글 없이 그 묶음까지, 2단은 머리글까지 더해 같은 묶음까지다.

## 확인

- 떨림을 낸 방식이 걷혔는지: 코드 — 머리글 관찰이 없고, 값은 요소 크기가 바뀔 때만 다시 잰다.
- 2단 높이와 1단 재생 줄 (360×780, 경로 5곡, 실측):

  ```
  1단   머리글 높이 0   --sheet-peek 158px   경로 지우기·순차 재생 y 567–600 < 플레이어 바 위끝 614
  2단   머리글 높이 55  --sheet-stop 208px   경로 지우기·순차 재생 y 566–599 < 플레이어 바 위끝 614
  ```

  2단 값은 1단에 있을 때 이미 208px 로 잡혀 있었다 — 머리글이 접힌 채 재도 필요값이 나온다. 경로 목록은 3단에서만 보인다(스크린샷).
