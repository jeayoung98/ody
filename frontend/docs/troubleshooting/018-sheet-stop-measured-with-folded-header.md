# 018. 1단으로 열린 여정 시트를 2단으로 올리면 재생 줄이 플레이어 바에 깔림

- 이슈: S15P21A405-714 (S15P21A405-712 와 맞물려 드러남)
- 커밋: `e41e5c27` · `400da72e`
- 날짜: 2026-09-27

## 증상

1. 폰(360×780)에서 출발·도착을 정해 경로를 만든다. 여정 시트가 1단으로 열린다(S15P21A405-712).
2. 시트 손잡이를 눌러 2단으로 올린다.
3. → 출발·도착 밑의 "총 재생 · 경로 지우기 · 순차 재생" 줄이 아래 플레이어 바에 반쯤 가려진다. 2단은 이 줄 아래에서
   멈춰야 한다(S15P21A405-714).

## 처음 의심한 것 (반만 맞았다)

"머리글이 펴지는 걸 모른다" — 맞았다. 그런데 머리글을 `ResizeObserver` 로 같이 보게 했더니(`e41e5c27`) 175 → 196px 로만
늘고 여전히 12px 모자랐다. 머리글의 **내용 상자**만 보고 있어서, 위아래 여백이 펴지는 동안은 알림이 오지 않았다.

## 증거

2단에서 시트 요소(`[data-sheet]`)의 `--sheet-stop` 과, 그 자리에서 `use-sheet-stop` 과 같은 식으로 다시 잰 값:

```
고치기 전      --sheet-stop 175px   다시 재면 208px   (33px 모자람 = 머리글 높이)
머리글 관찰    --sheet-stop 196px   다시 재면 208px   (12px 모자람 = 머리글 위아래 여백)
테두리 상자    --sheet-stop 208px   다시 재면 208px
```

"경로 지우기" 버튼은 고치기 전 y 599–632 였다(DOM). 플레이어 바 위끝은 스크린샷에서 어림하면 615 근처라 버튼 아래 절반이
깔렸다.

## 원인

`hooks/use-sheet-stop.ts` 는 **멈출 요소의 아래끝 − 시트 위끝**을 재고, 요소 **크기**가 바뀔 때만 다시 잰다.

`app/globals.css` 는 1단에서 머리글 높이·여백을 접는다(S15P21A405-703, "1단은 머리글 없이"). 그래서:

- 1단으로 **처음 열린** 시트는 머리글이 접힌 채로 잰다 → 요소가 머리글만큼 위에 있어 값이 짧다.
- 2단으로 올리면 머리글이 펴져 요소가 33px 내려가지만 요소 크기는 그대로라 다시 재지 않는다.

프로필(`feed-header`)은 같은 훅을 쓰지만 2단으로 열려 머리글이 펴진 채로 재기 때문에 드러나지 않았다. 여정이 712 에서
1단으로 열리게 바뀌면서 처음 드러났다.

## 조치

`use-sheet-stop` 이 시트 머리글(`[data-sheet] > section > header`)도 `ResizeObserver` 로 본다. **테두리 상자**로 본다
(`{ box: "border-box" }`) — 높이와 여백이 따로 애니메이션되므로 둘 다 끝날 때까지 알림이 와야 한다.

1단에서는 접힌 머리글 기준 값이 들어가지만 1단은 이 값을 안 쓴다(1단 높이는 `use-sheet-peek`). 2단으로 올라가는 동안
머리글이 펴지는 만큼 따라 늘어 제자리에 선다.

## 확인

360×780 에서 경로를 만들고(1단으로 열림) 2단으로 올려 위 표의 값을 다시 읽었다. 208px 에서 멈추고, 스크린샷에서 재생 줄
전체가 플레이어 바 위에 보인다. 경로 목록은 3단에서만 나온다.
