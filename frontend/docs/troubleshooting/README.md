반드시 남긴다. 원인을 잘못 짚었다가 되짚은 과정도 그대로 쓴다 — 그게 제일 쓸모 있다.

## 쓰는 법

### 규칙

1. **증상 → 증거 → 원인 → 조치 → 확인** 순서로 쓴다. 원인부터 쓰지 않는다.
2. **증거를 붙인다.** 콘솔 로그, 실제 값, 스크린샷에서 읽은 수치. "그래 보였다"로 끝내지 않는다.
3. **처음에 잘못 짚었으면 그것도 쓴다.** 왜 그렇게 보였는지가 다음 사람에게 가장 쓸모 있다.
4. **확인 방법을 적는다.** 고친 뒤 무엇을 보고 됐다고 판단했는지.
5. 파일 이름은 `NNN-영문-슬러그.md`. 번호는 순서대로.
