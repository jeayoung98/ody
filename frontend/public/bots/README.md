# 데모 봇 프로필 사진 (S15P21A405-536)

여기 둔 사진이 **주변 사람 레이더의 헬멧 바이저 안**과 목록의 동그란 사진에 들어간다.
지도 위 헬멧도 같은 사진을 쓴다.

## 넣는 법

1. 정사각에 가까운 사진을 이 폴더에 넣는다. 정사각이 아니어도 **가운데를 잘라** 쓴다
   (`lib/avatar-photo.ts` 의 `drawCropped`, CSS 는 `object-cover`).
   얼굴이 가운데에서 많이 벗어나 있으면 미리 잘라 두는 편이 낫다.
2. `src/lib/bots/roster.ts` 의 표에서 그 봇 줄의 `null` 을 파일 이름으로 바꾼다.

```ts
["효정봇", 322, "hyojung-yoshi.png"],   // null → 파일 이름
```

`null` 로 두면 코드가 만들어 내는 그라데이션 그림이 대신 뜬다. **없는 파일 이름을 적으면
목록에 깨진 이미지가 뜨므로**, 파일을 실제로 넣은 봇만 이름을 적는다.

## 크기

400×400 안쪽이면 충분하다. 바이저 안은 30px 남짓이고 목록은 30px 다.
큰 파일을 넣으면 첫 화면 로딩만 느려진다.
