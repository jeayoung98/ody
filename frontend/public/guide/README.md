# 도움말 안내 영상

`HelpDialog` 의 카드마다 한 편씩 들어간다 (S15P21A405-436).
**파일명이 곧 경로다** — `help-dialog.tsx` 의 `guideCards()` 에 적힌 `clip` 값과 맞춘다.

| 파일 | 카드 | 담을 동작 |
| --- | --- | --- |
| `map.mp4` | 별지도 | 별 한 번 클릭(곡 정보) → 한 번 더(재생) → 내 위치가 그 별로 옮겨가는 것까지 |
| `drill.mp4` | 파고들기 | 계속 확대 → 다음 레이어로 파고들기 → 새 축 2개로 재정렬 |
| `nearby.mp4` | 주변 탐색 | 곡 선택 → 이웃 10곡이 선으로 이어짐 |
| `journey.mp4` | 여정 | 출발·도착 지정 → 경로 생성 → 별을 하나씩 건너가기 |
| `follow.mp4` | 따라가기 | 탑승 → 화면이 따라 움직임 → 하차. **지금은 카드가 잠겨 있다** (`ody:guide-follow`) |

## GIF 를 쓰지 않는다

같은 화면을 GIF 로 담으면 **10~50배 커진다.** 실제로 파고들기 화면을 GIF 로 뽑았더니
2582x1556 에 **69MB** 였다. 저장소에 들어가는 것이라 그 크기가 곧 팀원 모두의 clone 비용이고,
**git 히스토리는 나중에 지워도 남는다.**

## 찍는 법

Windows 에 이미 있는 녹화기가 mp4 로 바로 뽑아 준다 — 따로 변환할 필요가 없다.

```
Win + Alt + R      녹화 시작 / 정지 (Xbox Game Bar)
```

결과물은 `영상/캡처` 폴더에 들어간다. 그걸 이 폴더로 옮기고 위 이름으로 바꾸면 끝이다.

## 규격

- **16:9** — 카드가 `aspect-video` 로 자리를 잡아 둔다. 다른 비율이면 잘린다
- 가로 **640~1280px**, 편당 **2MB 안쪽**. 카드 폭이 `max-w-md`(448px)라 그 이상은 낭비다
- 길이 **5~10초**. 한 동작만 담는다
- 소리는 안 쓴다 (`muted` 로 재생한다 — 그래야 자동재생이 막히지 않는다)
- 파일이 **없으면 자리만 비운다** — 넣기 전에도 문구는 읽힌다

## 찍을 때

감춘 기능(주변 사람·따라가기 등)을 찍으려면 설문 모드를 꺼야 한다.

```js
localStorage.setItem("ody:survey-mode", "false"); location.reload();
```

따라가기 카드를 보려면 하나 더 켠다.

```js
localStorage.setItem("ody:guide-follow", "true"); location.reload();
```
