## Notes

- 2026-09-17 A-30~A-32 검토: `size` 전달·기본 동작, `MapPoint.youtubeUrl` 제거 범위,
  지도 응답 PC 3자리 반올림의 수용 기준은 구체적으로 추가했다.
- A-30의 측정 단계 운영 상한은 10,000, 잘못된 `size`·`level` 값은 400 `INVALID_INPUT`으로 확정했다.
- 1레이어는 `size`를 반환 상한으로 적용하며, 요청값이 정적 표본보다 크면 가용 표본 전체를 반환한다.
- 1레이어는 현재 약 1천 건 정적 표본을 읽으므로 3,000·10,000 실측은 백엔드 연결만으로 불가능하다.
  공간 균등 성질을 유지한 더 큰 정적 표본을 준비하는 데이터 파트 작업이 선행 또는 병행돼야 한다.
- 검토 결과: 명세 갱신 완료. 팀 검토용 초안이며 명세 확정·구현 준비 완료로 판정하지 않는다.
- 이전 범위 입력 명세를 중심좌표 입력으로 교체했다. 동일 기능 디렉터리를 유지했고 중복 명세를 만들지 않았다.
- P1: 레벨·축 쌍·PC 생략/추가·좌표 제약의 계약이 미정이다. FR-001·FR-003·FR-004의 전체 정상/오류 조합 확정에 필요하다.
- P2: 중심좌표·level→후보 구역과 이전 선택 조건의 연결이 미정이다. FR-008 및 선정 종단 간 검증에 필요하다.
- P3: 대표곡 정의·선정·개수·순서·빈 결과·페이지 및 미명시 응답 제약이 미정이다. 정확한 기대 목록을 확정할 수 없다.
- C1~C4: 한 쌍/레벨별 축 개수, 공통 페이지 규약/major 응답, required/기본값, 주성분 적용 표현 차이를 보고했다.
- A1~A8은 확인된 계약만 검증한다. 선정 기준·개수·빈 결과가 결정된 것처럼 검증하지 않는다.
- SC-003·SC-004의 측정 환경·시간 예산·관측 방법은 D6의 계획 사항이다. 임의 성능 수치·백분위를 추가하지 않았다.
- API 이름·필드는 사용자 요청에 따른 기존 외부 계약의 추적 대상이다. 구현 세부사항 배제 지침을 이유로 이를 제거하지 않았다.
- 문서 공백을 보고해 달라는 요청에 따라 미결정 목록을 제시했으며, 답변을 추정하거나 선택지 답변을 강요하지 않았다.
- 다음 단계: P1~P3 팀 결정과 C1~C4 정합성 확인 후 명세 갱신·승인. D1~D6은 plan 단계에서 결정한다.
- 구현·자동화 기능 테스트·성능 검증은 미실행이다. 이 체크리스트의 표시는 문서 검토 결과다.
