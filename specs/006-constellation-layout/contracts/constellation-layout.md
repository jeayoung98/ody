# Contract: 별자리 배치 API

**Feature**: 006-constellation-layout | **BACKEND-NOTES**: A-9 | **기능 ID**: PATH-01
**협의 조합**: BE2(효정) ↔ FE1(주하) · BE4(재영)
**상태**: 제안 — 프론트 확인 대기

---

## 1. 엔드포인트

```text
POST /api/constellations/layout
Authorization: Bearer <accessToken>
Content-Type: application/json
```

경로는 A-9 문서와 프론트 상수(`API_ENDPOINTS.constellation.layout`)를 그대로 따랐다.
백엔드 다른 도메인이 단수형(`/api/music`, `/api/playlist`)이라 표기가 어긋난다 — 통일은 S15P21A405-213·214 에서 FE 와 함께 정한다.

## 2. 요청

```json
{ "musicIds": [10234, 88123, 4412, 900001] }
```

| 필드 | 타입 | 필수 | 규칙 |
| --- | --- | --- | --- |
| `musicIds` | `number[]` | ✅ | 2개 이상 30개 이하, 각 원소 1 이상, **중복 불가** |

**요청 본문의 다른 필드는 무시한다.** 프론트가 지금 함께 보내는 `points`(16차원 좌표)는 읽지 않는다 —
좌표 원천은 서버의 서빙 baseline 하나여야 모든 사용자가 같은 모양을 본다. 보내도 응답이 달라지지 않으므로,
프론트는 목 라우트를 걷어내는 시점에 같이 빼면 된다.

## 3. 응답 (200)

```json
{
  "success": true,
  "data": {
    "points": [
      { "musicId": 10234, "x": 1.0,      "y": 0.1823 },
      { "musicId": 88123, "x": -0.4471,  "y": -0.9032 },
      { "musicId": 4412,  "x": 0.2210,   "y": 0.6614 },
      { "musicId": 900001,"x": -0.7739,  "y": 0.0595 }
    ]
  },
  "error": null
}
```

| 필드 | 타입 | 보장 |
| --- | --- | --- |
| `points` | `array` | 요청 `musicIds` 와 **같은 개수·같은 나열 순서**. 누락 없음 |
| `points[].musicId` | `number` | 요청한 값 그대로 |
| `points[].x`, `points[].y` | `number` | `-1 ≤ 값 ≤ 1`. `y` 는 위가 양수. 자릿수 제한 없음 — 반올림은 프론트가 한다 |

### 이 응답이 보장하는 것

1. **결정성** — 같은 곡 집합이면 언제·누가·어느 레이어에서 불러도 같은 좌표다.
2. **순서 무관** — `musicIds` 를 섞어 보내도 각 곡의 `x`·`y` 는 같다(나열 순서만 요청을 따른다).
3. **비례 보존** — `x`·`y` 에 같은 배율을 적용한다. 축별로 늘리지 않으므로 모양이 찌그러지지 않는다.
4. **레이어 무관** — 요청에 레이어가 없고, 레이어가 달라도 같은 모양이다.

### 이 응답이 보장하지 않는 것

- **부분집합 안정성**: 곡 집합이 달라지면 축도 달라진다. 10곡 배치에서 1곡을 빼면 나머지 9곡의 좌표는 9곡짜리 배치의 좌표이지, 10곡 배치의 좌표가 아니다. 곡을 추가·삭제하면 모양 전체가 바뀌는 것이 정상이다.
- **서빙 좌표계와의 관계**: `x`·`y` 는 지도(PC 축) 좌표가 아니라 **그 집합만의 표시용 투영**이다. 지도 위치와 섞어 쓰면 안 된다.

## 4. 오류

공통 실패 구조: `{ "success": false, "data": null, "error": { "code", "message" } }`

| 상황 | HTTP | code |
| --- | --- | --- |
| `musicIds` 누락·빈 배열·1개·31개 이상·중복·0 이하 값 | 400 | `INVALID_INPUT` |
| 요청한 곡 중 하나라도 DB 에 없음 (또는 좌표 NULL) | 404 | `MUSIC_NOT_FOUND` |
| 인증 없음·만료 | 401 | (인증 계약을 따른다) |
| 그 외 서버 실패 | 500 | `INTERNAL_SERVER_ERROR` |

**부분 성공은 없다.** 없는 곡을 빼고 나머지로 배치를 만들면 모양이 조용히 달라지고 호출자는 알 수 없다.
중복도 조용히 합치지 않는다.
