# Data Model: 여정 역 수

**Feature**: 007-journey-station-count · **Date**: 2026-09-13

새 엔티티도, 스키마 변경도, 마이그레이션도 없다. 이 문서는 **값과 그 범위가 어떻게 바뀌는지**만 기록한다.

## 값

| 이름 | 뜻 | 출처 | 현행 | 변경 후 |
| --- | --- | --- | --- | --- |
| `L` | 끝점 거리 `‖B − A‖` | `AxisFrame.length` (좌표에서 계산) | — | 변화 없음 |
| `n` | 중간 정거장 수 | `AxisFrame.stationCount(...)` | `L≤10.7 → 10`, 초과 시 `clamp(round(10+(L−10.7)), 10, 20)` | `clamp(floor(L/s) − 1, 0, 18)` |
| `s` | 정거장 간격 하한 | **신규** `ody.journey.station-spacing` | — | 기본 `2.5` |
| `cap` | 정거장 상한 | `AxisJourneyPathFinder.MAX_STATIONS` | 20 (AxisFrame 안 상수) | **18** |
| `musicCnt` | 응답 곡 수 = `n + 2` | `JourneyResponse.musicCnt` | 12 또는 21~22 | **2 ~ 20** |

`s` 는 좌표계 `v2.1-pca16` 에 귀속된다. 번들이 바뀌면 다시 재야 한다(FR-006).

## 범위가 바뀌는 것 — `musicCnt`

| | 현행 | 변경 후 |
| --- | --- | --- |
| 최솟값 | 12 (`start == end` 인 1 은 별도 경로) | **2** |
| 최댓값 | 22 | **20** |
| 무작위 쌍 중앙값 | 12 | **6** |
| 무작위 쌍 p90 | 22 | **10** |

`start == end` 는 지금처럼 `musicCnt = 1` 로 따로 끊는다(004 FR-012). 변경 없음.

## 응답 계약

**바뀌지 않는다**(FR-007). 필드 이름·타입·`step` 연속성·정렬 모두 그대로다. `JourneyResponse`·`JourneyStop`·`MusicDetail` 어느 것도 고치지 않는다.

바뀌는 것은 `musicCnt` 와 `path.length` 가 **취할 수 있는 값의 범위**뿐이다. 스키마가 아니라 분포가 바뀌는 것이라 타입 변경은 없지만, 프론트에는 알려야 한다(FR-009).

## 상태 전이

없음. 여정은 요청마다 새로 계산하고 서버는 상태를 보관하지 않는다.

## 불변식

1. `0 ≤ n ≤ 18`
2. `musicCnt = n + 2` (단, `start == end` 이면 1)
3. `musicCnt ≤ 30` — 004 FR-008 계약 가드. `18 + 2 = 20 < 30` 이라 구조적으로 도달 불가
4. `n = 0` 이면 층 질의가 **0회** 나간다
5. `n ≥ 1` 이면 이웃 정거장의 축 방향 간격 `L/(n+1) ≥ s`
