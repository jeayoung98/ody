### 무작위 30쌍 (SC-007)

8쌍은 가까움 4·멂 4 로 편향돼 있어 **거리 5~19 구간이 비어 있다.** `pool.json` 에서 고정 시드로 30쌍을 뽑아 같은 지표를 재고, 축 한 칸이 `s` 미만인 쌍이 **0건**인지 확인한다.

**합격선**
- SC-001: 가까운 쌍 4개의 우회 배수가 **4 미만**
- SC-002: 모든 구간 거리가 **τ_far(4.912) 이하**
- SC-003: 모든 쌍에서 축 방향 한 칸 `L/(n+1) ≥ s`
- SC-007: 위 셋이 **8쌍과 30쌍 양쪽에서** 성립

측정 결과는 **이 표에 채워 커밋하고 MR 본문에도 싣는다.** 하네스가 저장소에 없으므로 근거는 문서에만 남는다.

### 판정

| 기준 | 결과 |
| --- | --- |
| SC-001 가까운 쌍 우회 배수 4 미만 | ✅ **1.00** (8.6 에서) |
| SC-002 구간 거리 ≤ τ_far(4.912) | ✅ 평균 3.63 · **최대 4.24** (8쌍·30쌍 전부 0건 초과) |
| SC-003 축 한 칸 ≥ `s` | ✅ 최소 2.51 (8쌍 2.55) |
| SC-004 20곡 이하 | ✅ 최대 11곡 |
| SC-005 가까운 쌍 오류 없이 짧은 목록 | ✅ 2곡, 200 |
| SC-007 8쌍·30쌍 양쪽 | ✅ 위 표 |

### 초안 SC-002 를 왜 폐기했나

구간 거리는 **역 수가 줄면 반드시 커진다.** 홉의 합은 끝점 거리보다 작을 수 없으므로 `구간 거리 ≥ L/(n+1)` 이고, `n` 을 줄이는 이번 변경과 **기계적으로 반대 방향**이다. 즉 SC-002 는 이 작업이 만족시킬 수 없는 기준이다.

고치기 전의 2.90 은 좋은 값이 아니라 **22곡이 옆으로 새며 얻은 값**이다(직선 22.9 에 경로 합 61.0). 지금은 경로 합이 33 이고 곡이 10개다.

**교체된 기준**(2026-09-13 승인): 이웃한 두 곡이 서빙 규칙이 정한 "유사하다" 범위 안에 있는가 — 즉 **구간 거리가 `τ_far`(4.912) 를 넘지 않는가.** `s = 2.5` 는 평균 3.63 · 최대 4.24 로 여유가 있고, `s = 3.5` 는 30쌍 중 12건이 넘겨 탈락한다. **2026-09-13 사용자 승인으로 SC-002 를 이 기준으로 교체했다.**

### 결정

**`s = 2.5` 를 유지한다.** 근거: (1) τ_far 초과 0건, (2) 우회 배수가 모든 구간에서 1.5 미만, (3) 30쌍 musicCnt 중앙값 6 으로 3.0·3.5 보다 길다. 2.3 은 곡이 더 많지만 축 한 칸 최소가 2.31 로 실측 반경 p50(2.272)에 붙어 여유가 없다.
